# Premium Ludo

A fully featured Ludo game with multiplayer, AI opponents, premium features, and modern UI.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Stack

- **Frontend**: Vanilla JS + CSS (no framework)
- **Backend**: Node.js + Express + Socket.IO
- **Database**: MongoDB
- **Hosting**: Free tier on Render/Netlify + MongoDB Atlas

## Documentation

See `docs/` folder for architecture, API spec, database schema, roadmap, and game rules.
